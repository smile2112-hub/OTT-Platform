## 📌 Purpose
FlowFlix is a full-stack OTT (Over-The-Top) streaming platform built as an academic project. It allows users to browse, search, and watch movies with subscription-based access, while admins can manage content and users through a dedicated dashboard.

---

## 🛠 Tech Stack
- **Frontend:** React.js, Bootstrap, Axios, React Router
- **Backend:** Spring Boot, Spring Security, Hibernate, JWT
- **Database:** MySQL
- **DevOps:** Docker, Docker Compose, Jenkins, Kubernetes

---

## ⚠️ Limitations
- Video streaming is limited to pre-uploaded files and does not support live streaming or adaptive bitrate (HLS/DASH).
- Payment integration uses a mock UPI flow and is not connected to a real payment gateway.
- The platform is designed for single-region deployment and does not currently support CDN-based content delivery.

---

## 🔭 Scope
- The platform supports end-to-end user journeys including registration, login, subscription purchase, movie browsing, and video playback.
- Admin users can manage movies, users, reviews, banners, and subscriptions from a centralized dashboard.
- The project demonstrates a production-ready architecture with containerization and CI/CD pipeline integration.

---

## 🚀 Future Enhancements
- Integrate a real payment gateway (Razorpay or Stripe) for subscription purchases.
- Add HLS-based adaptive video streaming for better performance across network speeds.
- Implement AI-based movie recommendation engine using user watch history and ratings.
- Scale the platform using Kubernetes with horizontal pod autoscaling and a CDN for media delivery.
